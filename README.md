# JetBot Lab

Notebook Python kiểu Jupyter để học lập trình JetBot ROS AI Kit trên sa bàn 3D.
Python chạy trong trình duyệt (Skulpt), đồ hoạ dùng Three.js. Đây là trang tĩnh, không cần build.

## Chạy thử trên máy
Mở `index.html` bằng trình duyệt, hoặc chạy `npx serve .`

## Triển khai Vercel
Import repo này vào Vercel, chọn Framework Preset là **Other** và để trống Build Command.
